# Mirage

Mirage is a systems programming language that aims to provide the freedom and
flexibility of C, with the conveniences and ergonomics of modern languages.

Mirage takes a lot of inspiration from C, C++, Rust, Zig, Go, Odin, and others.
If you've used any of these languages you'll probably recognize their influence
throughout.

It's built primarily as my own ideal language, not as a replacement for anything
that already exists.

## Disclaimer

This project is still very much in an experimental stage and should be
considered unstable. Existing features are subject to potential breaking changes
or complete overhauls.
